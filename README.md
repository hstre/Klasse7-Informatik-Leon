## GitHub Pages

Die Dateien `index.html`, `styles.css` und `app.js` gehören gemeinsam in das
Hauptverzeichnis des Branches `main`. Die Seite benötigt keine Installation und
keinen Build-Schritt.

In GitHub unter **Settings → Pages** als Quelle **Deploy from a branch**, danach
den Branch **main** und den Ordner **/(root)** wählen.
